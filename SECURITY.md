# Security policy

Please report a suspected vulnerability privately to the corresponding author
through the contact address in the associated manuscript rather than opening a
public issue. Include the affected version, a minimal reproduction, and the
expected impact. Research-result disagreements and reproducibility questions
belong in the public issue tracker once the repository URL is available.

Only the latest tagged release is supported. Never include access tokens,
private datasets, personally identifying paths, or unpublished reviewer
material in a report or reproduction bundle.
